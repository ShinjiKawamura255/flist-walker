# VM-006: CI coverage gate / GUI validation docs

Back to the [Validation Matrix](../validation-matrix.md). Read the [coverage/GUI-validation checklist](../validation-matrix.md#ci-coverage-gui-validation-docs-or-smoke-script-changes).

## Typical Targets

GUI plan/report text, coverage command/policy, GUI smoke scripts, canonical TSV inventory and checked-in fixtures. Select by the actual changed responsibility, not the presence of VM-006 alone.

## Required Validation

| Changed surface | Required checks |
| --- | --- |
| Plan/template/policy text only | Affected diff, GSM/TC IDs, Markdown links, plan/template/selection consistency, repository contract and independent release-policy review when release gates change. No Rust/coverage, fixture regeneration, headful or wrapper run required |
| Coverage command/threshold/instrumentation | Fresh coverage using `cd rust && mkdir -p target/llvm-cov && cargo llvm-cov --locked --workspace --lcov --output-path target/llvm-cov/lcov.info --fail-under-lines 75` (PowerShell: `New-Item -ItemType Directory -Force target/llvm-cov`); changed workflow/threshold review |
| Fixture/hash/count validation | Canonical hash/FileList count and corrupt-copy rejection, fixture script and its affected unit tests |
| Deterministic TSV/wrappers | TSV schema/group inventory, `--lib`, nonzero/ignored-test guards and both changed platform wrappers (unchanged wrappers may reuse valid evidence) |
| Headful staging/report/safety | Changed Bash/PowerShell parser and focused staging tests: exact allowlist, no updater artifacts, settings isolation, report preservation, early exit handling |
| Windows scripted-query probe | Changed parser and PID-bound window/WM_NULL/query-trace assertion tests; affected Windows execution |

For selected tooling rows run relevant repository-tooling tests. Check changed references with `rg -n "GUI-TESTPLAN|GUI-TESTREPORT|GUI-HEADFUL-SMOKE|GUI-DETERMINISTIC|gui-smoke-fixture|gui-headful-smoke|gui-deterministic-scenarios|ScriptedQueryProbe|GSM-"` over affected docs/scripts. Screenshot rejection remains part of the repository contract. Workflow behavior changes also select VM-009.

## Optional, Manual, Or Follow-Up

[Release Validation Selection](../release-validation.md) owns evidence reuse; Deterministic / Native interaction / Liveness remain independent. Headful launch uses a fresh owned staged copy and isolated settings. It is a changed-startup/backend/packaging or nightly check, not a full native matrix and not a normal PR required CI check. The 75% threshold and existing CI coverage enforcement remain unchanged; increasing the threshold requires a fresh baseline and updated policy.
