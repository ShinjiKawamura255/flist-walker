## Added
- Settings に検索クエリの復元設定を追加した。前回のタブを復元するとき、root・filter・active tab を保ったまま検索欄だけを空にできる。既存設定では従来どおりクエリを復元する。
- Settings に System / Dark / Light のテーマ設定を追加した。保存した設定は次回起動時から適用する。
- インデックス作成の現在タブ／全タブ停止と、対象タブだけを再開する Refresh Index を追加した。停止・失敗時も直前に確定した検索結果を保持する。

## Changed
- Settings と関連ダイアログの確定操作を右下へ揃え、確定操作、Cancel の順に並べた。JSON 操作と Reset は確定操作から分離した。
- 履歴保存と Warm 更新の回帰テストを、実際の保存完了と延期された要求の状態に合わせて強化した。検証用一時ディレクトリの衝突防止と、実際の runtime settings との整合確認も追加した。
- GUIのインデックス処理を上限付きの子プロセスへ隔離し、停止したファイルシステム処理の取消・終了確認と、回復後の要求受付を改善した。
- Linux coverageの異常終了診断、非同期処理の進捗・取消判定、TC-207のwall時間／thread CPU時間の観測を強化した。TC-207の100ms閾値は維持する。

## Fixed
- Light テーマで検索一致文字、種別ラベル、現在行マーカーが薄くなる配色を修正し、通常行・選択行で読み取りやすくした。Dark テーマの既存色は維持する。
- リリース前検証に公開済み v0.30.2 の updater capability と、v0.31.0 の exact checksum inventory に対する前版互換性回帰テストを登録した。
- 初回インデックス中のSource表示、横スクロール時のタブ追加ボタン、フォントや複数行Rootに依存する文字切れと行配置を修正した。
- Browseの開始フォルダ確認をUIスレッドから移し、古い応答やダイアログ取消・終了後の応答を無視するようにした。
- macOSのリリースビルドが固定Rust版を使用するよう修正し、Windows測定ヘルパーのタイムアウト時にも途中出力を保持するようにした。
- CI用Cargoツールの導入でRust版を明示し、暗黙のコンパイラ選択を防ぐ回帰テストを追加した。
- Windows配布物のREADMEで、Ignore Listのファイル名が欠落する問題を修正した。

## Security
- TLS証明書検証の依存を `rustls-webpki 0.103.16` / `webpki-roots 1.0.10` へ更新し、信頼失効したemSign中間証明書を受け入れる問題（[RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382)、[RUSTSEC-2026-0381](https://rustsec.org/advisories/RUSTSEC-2026-0381)）へ対応した。
- 取り下げられたWindows clipboard依存 `clipboard-win 5.4.1` を `5.4.3` へ更新し、HTML fragmentの境界検証・コピー処理の修正を取り込んだ。
- 自動更新は埋め込み公開鍵で `SHA256SUMS.sig` を検証した後、対象ファイルのSHA-256を照合します。検索履歴は既定で平文保存され、`history_persist_disabled=true` で永続化を無効にできます。

## Known issues
- macOS 配布物は未 notarized。
- TC-207の過去の100ms超過の原因は未確定。wall時間とthread CPU時間を分けた計測を追加したが、OSスケジューリングトレースは未実施であり、実処理の遅延とスケジューリング待ちの原因を確定していない。
- 変更したGUIの実操作（設定・表示・Browse・停止／再開）、Windows起動性能TC-193とclipboard動作、実OSテーマ通知、実共有フォルダ切断／復旧は未検証。本版限定で未実施を受容しており、実機での表示・入力・復旧・性能には未確認リスクが残る。
- 過去のLinux coverage実行中のSIGSEGVは原因未確定。元の失敗と診断証跡を保持し、本版の新しいCI・coverage検証とは区別する。
- v0.24.3 利用者は同じ variant の binary と `SHA256SUMS` を手動で取得・検証して一度置き換える必要がある。v0.24.4 以降は通常の自動更新を利用できる。
- 大規模な候補集合では query 準備中の index 取り込みを一時停止する。v0.30.0 の50万候補検証の query dispatch 中央値339〜498 ms、最大536 msは元版の観測値であり、本版の再測定値ではない。
- 未実施のGUI・性能検証と原因未確定事項の受容はv0.31.0限定です。100ms、起動性能比0.70、coverage75%の判定基準は変更していません。
