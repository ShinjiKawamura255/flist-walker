## Added
- プリセットの Add/Edit に任意の `Search text` を追加しました。Picker では表示名と検索用文字列を別々に曖昧検索し、表示名の一致を優先します。

## Changed
- CLI/TUI（`fw` を含む）は `.flistwalker_cli_config.json`、GUI は `.flistwalker_config.json` を使います。CLI設定がない初回は既存のGUI設定を元ファイルに触れず複製します。検索履歴・名前付きルート・プリセットは引き続き共有します。
- Settings の保存成功後、テーマと検索関連の設定が再起動なしで反映されます。検索語の復元設定は次回のタブ復元時に適用されます。
- 直前の安定版で更新用マニフェストを読めることを確認する回帰テストを追加し、固定Rustと最新stableのCI検証を整理しました。

## Fixed
- Settings の選択コントロールの位置と、操作中・無効時のラベル色を修正しました。
- 狭い画面でのプリセット Add/Edit と、開いたままウィンドウを縮めた Picker の左右の見切れを修正しました。
- インデックス更新の引継ぎ、TUI終了時の待機、Windowsの設定保存テストの完了判定を改善しました。

## Breaking
- CLI/TUI の設定を外部から編集する場合は、新しいCLI向けファイルを対象にしてください。`--preset NAME` の `NAME` は従来どおり表示名です。

## Deprecated
- なし。

## Security
- 推移依存の `rustix` を `1.1.6` に更新しました。[RUSTSEC-2026-0486](https://rustsec.org/advisories/RUSTSEC-2026-0486.html)
- 自動更新は埋め込み公開鍵で `SHA256SUMS.sig` を検証し、`SHA256SUMS` と配布物を照合します。
- 検索履歴は既定で平文保存されます。永続化を無効にするには `history_persist_disabled=true` を設定してください。

## Known issues
- macOS 配布物は未 notarized（Appleの公証なし）で、Developer ID署名もありません。
- v0.33.1 のCLIで同じ名前のプリセットを上書きすると `Search text` が消えるため、GUI/CLIの版を揃えてください。
- 設定ファイルを直接変更した場合は、Settingsで再読込して保存するか、再起動してください。
- v0.24.3 の updater は現在のマニフェストを読めません。同じ種別のバイナリと `SHA256SUMS` を取得・検証し、一度手動で置き換えてください。
