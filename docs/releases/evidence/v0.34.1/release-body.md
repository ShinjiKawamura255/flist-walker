## Changed
- 大きな索引を検索するとき、順位に必要な情報に絞って候補を準備します。パス順で上位だけを表示する場合は、表示に必要な件数だけを先に選びます。
- 除外ルールを使わないバッチCLIでは候補のコピーを省きます。また、索引を別プロセスから受け取る際に同じ項目を二度変換しません。
- ライトテーマではボタンと背景の差を広げました。どちらのテーマでも、タブやボタンに文字が収まりやすく、幅を狭めても検索欄を残します。
- v0.34.0から更新する場合のチェックサム一覧を検証する回帰テストを追加しました。

## Fixed
- タブの名前と閉じる記号を縦中央に揃え、隣り合うボタンやチェックボックス、ドロップダウンの文字のずれを直しました。

## Security
- 依存クレートの `url` を2.5.9に更新し、RUSTSEC-2026-0592に対応しました。必要な `form_urlencoded` も1.2.3に更新しました。

## Known issues
- macOS向け配布物はAppleの公証を受けていません。
- macOS実機でのライト／ダークテーマと狭いウィンドウの表示は、この版では未確認です。
- v0.24.3から更新する場合は、同じ配布形式のバイナリを取得し、SHA256SUMSで照合して一度置き換えてください。

## Verify checksum
同じリリースの配布物と `SHA256SUMS` を取得して照合してください。自動更新では `SHA256SUMS.sig` の署名も検証します。

PowerShell:
```powershell
Get-FileHash -Algorithm SHA256 .\FlistWalker-0.34.1-windows-x86_64.exe
Get-FileHash -Algorithm SHA256 .\FlistWalker-0.34.1-windows-x86_64.zip
```

bash:
```bash
sha256sum -c SHA256SUMS
```
