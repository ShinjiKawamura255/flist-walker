The user approved this known issue for v0.29.0 only; the keyboard contract remains open and the mouse path is disclosed publicly.
- Windows real UNC, external Open/Reveal, clipboard/copy, IME composition, alternate DPI or multiple displays, updater loopback or signed apply, fixed 500,000-entry pressure, and all dialog/persistence failure permutations remained `NOT RUN`. The user approved a one-time v0.29.0 residual deviation; deterministic and representative native evidence did not relabel these axes PASS.
- macOS native `GSM-001..013` remained `NOT RUN` because no native macOS session was available. The user approved a one-time v0.29.0 waiver; CI tests/builds were not presented as native GUI PASS.
- Candidate run `36237306042` had one accepted external `actions/download-artifact@v8.0.1` Node `[DEP0005] Buffer()` warning.
- Tagged run `36248617696` had two accepted warnings from that same Action and one rustup notice that the repository toolchain file selected Rust 1.97.1 during cargo-audit installation. The user approved only those exact emissions for that run and release. No exception carries forward.

## Known Limitations

- Paged-preview Color can be toggled with the mouse in v0.29.0 but lacks a reachable keyboard operation.
- macOS artifacts are unnotarized.
- The v0.24.3 updater cannot parse manifests containing `fw-*`; v0.24.3 users require one manually verified binary update before normal updates resume.
