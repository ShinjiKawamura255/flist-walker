### TC193 operator follow-up

Freeze the Windows native TC193 load metric, sampling cadence, threshold, and before/during/after acceptance window before starting. Prefer independent total Processor Time via PDH, and retain the actual violating sample if the gate fails. For this session that method was sampled every two seconds; accepted samples stayed under the session's 25% precondition (peak 5.55%). A separate same-environment comparison observed a processor-load proxy at 48% while PDH Processor Time reported 3.32% (Processor Utility 4.86%); a separate PDH observation range was 3.04–7.03%. The values are not interchangeable in this environment. Investigate disagreement before pausing instead of relying on the proxy alone; these measurements say nothing about historical machine load and do not establish a general CPU rule. This is a versioned operating recommendation, not a change to project-wide validation policy, TC193 correctness/performance thresholds, or CI.
