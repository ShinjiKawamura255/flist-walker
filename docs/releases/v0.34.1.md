## Native validation and limits

The [native evidence](evidence/v0.34.1/native-validation.json) records the original Windows GNU candidate TC193 result: 200 paths, five warmups and 25 samples per variant, 76.1402 ms universal and 30.9342 ms for `fw` (ratio 0.406279; maximum 0.70), with equal output and no errors. This is reused for TC193 only. The tagged Windows executables were not measured: their code and imports match, with differences limited to timestamps, PE checksums and order of unchanged version entries. New distribution bytes and static Windows checks were verified separately.

Mac native light/dark and narrow-width rendering was **NOT RUN**: Computer Use disallowed opening Terminal for the isolated launch, and the candidate never started. The owner accepted that deviation for v0.34.1 only. Passing macOS CI does not substitute for visual verification, and the deviation does not carry forward. The Mach-O distributions are not Developer ID signed or notarized; the Ed25519 signature covers the update manifest.
